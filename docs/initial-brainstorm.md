# Initial request

Create a focused macOS Markdown preview app that works with Finder's **Open
With** and can optionally become the default `.md` application. Investigate and
support Finder Spacebar Quick Look where possible. View one independent file at
a time, support dark mode, and provide reliable full-content font scaling.
Expose File menu exports to text, HTML, PDF, and related formats, plus commands
to copy the original Markdown, rendered plain text, and rich text suitable for
Slack or Confluence.
