# Architecture

The app has three layers:

1. `MarkdownCore` parses Markdown into simple block values and renders native
   attributed text, semantic HTML, plain text, RTF, and paginated PDF.
2. `MarkdownPreviewApp` uses `NSDocument` and `NSDocumentController`; each open
   file owns one independent window and a read-only `NSTextView`. Documents use
   NSFilePresenter notifications plus a lightweight vnode watcher to notice both
   coordinated edits and editors that atomically replace files. Reloads are
   debounced, read through `NSFileCoordinator`, and applied while preserving
   the text view's selection and scroll position.
3. `MarkdownPreviewQuickLook` is a view-based Quick Look extension. It reads the
   requested file and displays native attributed text generated by
   `MarkdownCore`, avoiding Finder's cache of data-based preview replies.

The main app and extension compile the same parser and native attributed-text
renderer. The extension has no dependency on the running app and does no
network access. Font scale is
stored in the app's private preferences and mirrored into a dedicated shared
preference domain. The app has write access only to that domain and Quick Look
has read-only access. Values are clamped before use. The app broadcasts changes
through a notification so existing windows rerender from source; newly opened
Quick Look previews read the same persisted scale.

Markdown parsing deliberately treats raw HTML as text. This keeps previews
self-contained and prevents a viewed document from injecting scripts or
loading remote content.
